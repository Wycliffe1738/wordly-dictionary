
# Wordly Dictionary SPA

## Project Description
Wordly is a Single Page Application built using HTML, CSS, and JavaScript. It allows users to search for English words and retrieve definitions from a public dictionary API.

## Features
- Search for words
- Display definitions and parts of speech
- Show pronunciation and play audio where available
- Display synonyms and example sentences where available
- Save and remove favorite words
- Store favorites using localStorage
- Switch between light and dark themes
- Handle errors for missing words and failed requests
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Free Dictionary API
- Git and GitHub

## How to Run
1. Clone the repository.
2. Open the project folder in your terminal.
3. Run `python3 -m http.server 8000`.
4. Open http://localhost:8000 in your browser.
